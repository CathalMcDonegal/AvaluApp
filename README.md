# AvaluApp

Aplicació web progressiva per gestionar cursos, classes, alumnes i avaluacions.

## Estat actual
- Dashboard de cursos
- Creació de cursos
- Creació de classes/grups
- Alta d'alumnes
- Persistència local amb localStorage
- PWA instal·lable
- Interfície responsive en català

## Full de ruta
1. Gestió completa d'alumnes i importació Excel/PDF
2. 1r, 2n i 3r trimestre
3. Ítems d'avaluació configurables
4. Avaluació global
5. Informes Word amb plantilles
6. Còpies de seguretat i exportació

## Desenvolupament
AvaluApp està pensada per GitHub Pages i comença sense backend: les dades de l'MVP es guarden localment al navegador. L'arquitectura queda preparada per separar persistència i serveis quan siguin necessaris.

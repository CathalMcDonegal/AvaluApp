# AvaluApp

Gestió de cursos, classes, alumnes i avaluacions.

## Funcionalitats
- Cursos i classes
- Alumnes
- Fitxa individual
- Tres trimestres i avaluació global
- Ítems d'avaluació
- Observacions
- PWA responsive

## Properes fases
Importació Excel/PDF, editor d'ítems, informes Word amb plantilles, impressió/PDF i còpies de seguretat.
